TScalc とは

2001年に Windows CE(Pocket PC)用に作った関数電卓 TScalc を、Windows 向けに作り直したアプリです。式をそのまま打ち込んで計算します。

  • sin・cos・tan、log・ln、√、累乗、累乗根、eˣ、π、1/x、×10ⁿ(指数表記)
  • 角度の単位は DEG / RAD を切り替えられます
  • 過去の計算が表示部に残り、クリックするとその式からやり直せます
  • キーボードでも操作できます
  • 直前の答えは Ans キーで次の計算に使えます

使い方

  1. キーで式を入力し、= で計算します。入力中も、計算できる式なら途中の結果が表示されます。
  2. 答えのあとに + − × ÷ などを押すと、その答えに続けて計算できます。
  3. 上に並ぶ過去の計算をクリックすると、その式に戻って直せます。
  4. 式をクリックすると、その位置にカーソルが移ります。‹ › でも動かせます。
  5. 答えをクリックするとコピーできます(Ctrl+C でも)。
  6. DEG / RAD で角度の単位(度・ラジアン)を切り替えます。
  7. 右上の「?」でアプリ内のヘルプ、時計のボタンで計算履歴の一覧が開きます。

よくある質問

0.1+0.2 が 0.3 になりますか

なります。コンピューターの小数の誤差は、有効15桁で丸めて表示しています。

エラーが出ました

0 で割る、負の数の平方根、log(0)、tan(90°) などは計算できないため、理由を表示します。カッコの閉じ忘れは、式の最後であれば自動で閉じて計算します。

履歴を消したい

時計のボタンで計算履歴の一覧を開き、「すべて消去」を押してください。アプリをアンインストールしたときも消えます。

表示が英語になります

Windows の表示言語が日本語以外のときは英語で表示します。

ウィンドウの大きさ

ウィンドウは自由に大きさを変えられます。横に広げると、表示部とキーを左右に並べます。

動作環境

Windows 10(バージョン 1809)以降・Windows 11(64ビット)。Microsoft Store から入手できます。
